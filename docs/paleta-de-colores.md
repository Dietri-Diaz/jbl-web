# Paleta de colores de la marca JBL

| Nombre | Código HEX | Uso previsto |
|--------|-----------|--------------|
| Naranja JBL | `#ff6a00` | Color de acento, botones y enlaces |
| Negro | `#111111` | Textos y fondo de la cabecera |
| Gris claro | `#f4f4f4` | Fondos de las tarjetas de producto |
| Blanco | `#ffffff` | Fondo general del sitio |

Los colores se declaran como variables CSS en `css/estilos.css`.
